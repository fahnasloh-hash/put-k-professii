## 1. Что это за проект

- **Тип:** статический сайт (чистый HTML + CSS + один общий `app.js`). Без
  бэкенда, без сборки, без npm. Раздаётся через **nginx**.
- **Хостинг:** контейнер на **Amvera** (Docker, `nginx:alpine`, порт 80).
- **Задача сайта:** SEO-страницы под запросы «вузы Москвы», «колледжи после 9
  класса» и т.п. + форма заявки, которая шлёт лид в Telegram.

### Структура
```
index.html                  — главная
styles.css                  — все стили (одна таблица, cache-bust ?v=ДАТА)
app.js                      — общий скрипт: навигация, FAQ, маска телефона,
                              модалка заявки, отправка в Telegram
nginx.conf                  — конфиг nginx (подключается в Dockerfile)
Dockerfile / amvera.yml     — деплой-конфиг (НЕ ТРОГАТЬ без нужды)
data/                       — Python-данные для генератора (institutions.py и пр.)
scripts/gen.py              — генератор страниц каталога из data/
vuzy-moskvy/  vuzy-moskovskoy-oblasti/  kolledzhi-moskvy/

```

## 3. ⚠️ ГЛАВНОЕ ПРАВИЛО ДЕПЛОЯ (из-за этого был 503!)

**Amvera собирает сайт ТОЛЬКО из remote `amvera`, ветка `master`. НЕ из GitHub.**

Если запушить изменения только в `origin` (GitHub) — на живом сайте **ничего не
изменится**, и старый битый билд продолжит отдавать **503 Service Unavailable**.
Именно на этом была потеряна целая сессия отладки.

### Как правильно деплоить:
```bash
git push amvera <твоя-ветка>:master
```
В ответ Amvera пишет `Detected changes in master branch` и пересобирает Docker-
образ (~1–2 мин). После этого проверь, что сайт открывается (а не 503).

Рекомендуется пушить в оба remote:
```bash
git push origin <ветка>:main      # зеркало на GitHub
git push amvera <ветка>:master    # реальный деплой
```

Если после пуша в `amvera` всё равно 503 — это уже реальная ошибка сборки,
смотри **Логи сборки** в панели Amvera.

## 5. Как продолжать кодить

- **Контент каталога** генерится из `data/*.py` через `scripts/gen.py`. Если
  меняешь данные вузов/колледжей — правь `data/`, потом перегенери страницы
  скриптом, а не редактируй сотни HTML вручную.
- **Стили** — только в `styles.css`. При изменении подними версию cache-bust
  параметра `?v=YYYYMMDD` в ссылках на css (иначе у юзеров останется старый кэш).
- **Форма заявки / Telegram** — в `app.js` (токен и chat_id зашиты там же).
- **SEO — приоритет №1:** не ломай `<title>`, мета-теги, JSON-LD разметку,
  хлебные крошки, внутренние ссылки и `sitemap.xml`. Это ядро ценности сайта.
- После каждого изменения, которое должно попасть на сайт — **пуш в
  `amvera:master`** и проверка, что сайт жив.
