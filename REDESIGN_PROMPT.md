## Контекст проекта

Это статический SEO-сайт (вузы и колледжи Москвы и области + заявки в Telegram).
**135 HTML-страниц, но почти все генерируются из шаблонов.** Не редактируй
сгенерированные HTML вручную — они затрутся при следующей генерации.

### Как устроена генерация (ВАЖНО)
- **`scripts/gen.py`** — генератор. Читает данные из `data/*.py` и пишет 114
  страниц + `sitemap.xml`.
- **`data/*.py`** — ДАННЫЕ (контент). Их **трогать НЕ нужно** для редизайна:
  - `data/institutions.py` — вузы и колледжи (slug, abbr, name, full, type,
    budget, dirs, desc, city, photo)
  - `data/faculties.py` — факультеты/направления
  - `data/cities.py` — города Подмосковья
  - `data/articles.py` + `data/articles_b2.py` — лонгриды по профессиям
- **`styles.css`** — все стили (один файл).
- Запуск генерации:
  ```bash
  python scripts/gen.py
  ```
  (на Windows: `/c/Python314/python scripts/gen.py`)

### Какие страницы НЕ генерируются (правятся вручную как обычный HTML)
`index.html` (главная), `it-kolledzh-moskva/`, `kuda-postupit-posle-9-klassa/`,
`meditsinskie-kolledzhi-moskvy/`, `pomoshch-s-postupleniem/`,
`postuplenie-2026/`, `privacy/`, `blog/`.

## ЗАДАЧА: редизайн

Цель — обновить визуальный дизайн сайта, **сохранив весь контент, SEO и систему
генерации**. Редизайн делается на уровне ШАБЛОНОВ и CSS, а не отдельных страниц.

### Где менять дизайн (функции-шаблоны в `scripts/gen.py`)
| Функция | Что рендерит | На сколько страниц влияет |
|---------|--------------|---------------------------|
| `head()` | `<head>`, подключение шрифтов/CSS | все генерируемые |
| `NAV` | верхнее меню + мобильное | все |
| `FOOTER` | подвал + sticky-CTA | все |
| `card()` | карточка вуза/колледжа | хабы, города, факультеты |
| `hub_page()` | шаблон хаб-каталога | 4 хаба |
| `detail_page()` | карточка вуза/колледжа (детальная) | 83 страницы |
| `fac_hub()` / `fac_detail()` | факультеты | 32 страницы |
| `goroda_hub()` / `city_page()` | города | 8 страниц |
| `article_block()` | лонгрид-статья профессии | внутри факультетов |

**Основную визуальную работу делай в `styles.css`** (цвета, типографика,
отступы, тени, скругления, сетки, кнопки, карточки). Структуру HTML в шаблонах
меняй только если этого требует новый дизайн.

## ЖЁСТКИЕ ПРАВИЛА (НЕ НАРУШАТЬ)

1. **НЕ редактируй контент в `data/*.py`** — это смысловое ядро, его не трогаем.
2. **НЕ правь сгенерированные HTML напрямую** (всё, что в `vuzy-moskvy/*/`,
   `vuzy-moskovskoy-oblasti/*/`, `kolledzhi-*/*/`, `fakultety/*/`, `goroda/*/`).
   Меняй шаблон в `gen.py` → перегенерируй.
3. **Сохрани SEO без потерь:** `<title>`, `<meta description>`, `<link canonical>`,
   Open Graph, JSON-LD (BreadcrumbList, FAQPage, EducationalOrganization,
   ItemList), хлебные крошки, теги `<h1>/<h2>/<h3>`, внутренние ссылки,
   `sitemap.xml`. Дизайн меняем — разметку для поисковиков нет.
4. **Сохрани заявки:** все кнопки с атрибутом `data-apply` и форма
   (`data-apply=""`) должны работать — они вызывают модалку и отправку в Telegram
   из `app.js`. Не удаляй эти атрибуты.
5. **Cache-bust:** при изменении `styles.css` подними версию — в `gen.py`
   константа `CSS_VER = '20260605'` (поставь новую дату). Она используется и для
   css, и для `app.js`. На вручную-правящихся страницах (`index.html` и др.)
   обнови `?v=...` в ссылках на css вручную.
6. **После любой правки шаблона/CSS — обязательно запусти `python scripts/gen.py`**
   и закоммить и сгенерированные страницы тоже.
7. **Мобильная адаптивность** обязательна (значительная часть трафика — телефоны).

## ДЕПЛОЙ (КРИТИЧНО)

Сайт хостится на **Amvera** и собирается **ТОЛЬКО из git-remote `amvera`,
ветка `master`** (НЕ из GitHub). Пуш только в GitHub на сайт не влияет.

```bash
git add -A
git commit -m "Redesign: <что сделал>"
git push origin <ветка>:main      # зеркало на GitHub
git push amvera <ветка>:master    # реальный деплой на Amvera
```

После пуша в `amvera` подожди 1–2 мин и проверь, что сайт открывается (не 503).
Если что-то сломалось — есть метка отката `stable-backup`:
```bash
git push amvera stable-backup:master --force
```
